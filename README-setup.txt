1. GitHub Pages で公開する
--------------------------------------------------
  (1) GitHubで「mitinoeki」という名前のリポジトリを作ります（公開＝Public）。
  (2) mitinoeki フォルダの「中身」をすべてアップロードします。
      リポジトリの一番上に index.html、sitemap.xml、robots.txt、assets フォルダなどが
      並ぶ状態にしてください（mitinoeki フォルダごと入れると URL がずれます）。
      ※「.nojekyll」という名前の空ファイルも一緒にアップロードしてください。
        パソコンの設定によっては見えないファイルなので、見つからない場合は
        GitHub上で「Add file → Create new file」から同じ名前で空のファイルを作れます。
  (3) リポジトリの Settings → Pages → Build and deployment で
      Source を「Deploy from a branch」、Branch を「main」「/(root)」にして Save。
  (4) 数分後に https://leben-k.github.io/mitinoeki/ で表示されます。
  ※ GitHub Actions は使いません。


2. 広告をGoogleスプレッドシートから表示する
--------------------------------------------------
  (1) Googleスプレッドシートを新しく作り、「ファイル → インポート」で
      「ad-sheet-template.csv」を読み込みます（1行目は見出しなので消さないでください）。

      列の意味
        A 番号 ………… 1, 2, 3 … と重ならない番号
        B 表示ページ … 空欄＝全ページ。ページを限定したいときだけ記入
                          例） index（トップページだけ）
                               kanko/（観光地ページすべて）
                               eki/（道の駅ページすべて）
                               kanko/tottori-sakyu（鳥取砂丘のページだけ）
                               複数のときは「,」で区切る
        C 広告コード … 楽天アフィリエイト（ふるさと納税を含む）などの作成画面でコピーしたコードを
                          そのまま1つのセルに貼り付けます（書き換え不要）

  (2) 「ファイル → 共有 → ウェブに公開」を開き、
      公開する範囲で広告のシートを選び、形式を「カンマ区切り形式（.csv）」にして「公開」。
      表示されたURLをコピーします。
  (3) mitinoeki/assets/js/config.js をメモ帳などで開き、
        adSheetCsvUrl: ""
      の "" の間にURLを貼り付けて保存し、GitHubへアップロードし直します。
        例） adSheetCsvUrl: "https://docs.google.com/spreadsheets/d/e/xxxx/pub?gid=0&single=true&output=csv"
  (4) 以後は、シートを書き換えるだけで全ページの広告が入れ替わります
      （反映まで数分かかることがあります）。

  広告の出方
    ・各ページに「広告」の枠が1つあります（トップページと一覧ページは2つ）。
    ・ふるさと納税の広告と通常のアフィリエイト広告は区別せず、同じ表にまとめて入れます。
    ・枠には、表の広告の中からページごとに違うものが選ばれます。
      同じページに同じ広告が2回出ることはありません。
    ・広告が1つもないとき、または読み込めないときは、枠ごと非表示になります。
    ・URLを設定する前は、枠の位置がわかるように「広告枠」と表示されます。
    ・サイト全体で10個ほどの広告を想定しています（行を増やせばそれ以上も可）。

  広告コードについて
    ・コードは一切書き換えずにそのまま表示します。クリック数・表示回数は、
      各アフィリエイトサービスのマイページでこれまで通り確認できます。
    ・<script> を含むコード（楽天モーションウィジェットなど）も表示できます。
    ・画像の大きさは、各サービスのリンク作成画面で選んでください。
      広告枠は300×300ピクセルの正方形を想定しています。
      スマートフォンの画面より大きい画像は、画面幅に合わせて縮小表示されます。
    ・広告枠には「広告」の表示が自動で付きます（ステルスマーケティング規制への対応）。


3. Google Search Console に登録する
--------------------------------------------------
  (1) Search Console で「URL プレフィックス」を選び、
        https://leben-k.github.io/mitinoeki/
      を入力します。
  (2) 所有権の確認は「HTMLファイル」を選び、ダウンロードした
      google〇〇〇〇.html を mitinoeki リポジトリの一番上にアップロードして「確認」。
  (3) 左メニュー「サイトマップ」に
        sitemap.xml
      と入力して送信します。
  (4) 早く載せたいページは「URL検査」でURLを入れ、「インデックス登録をリクエスト」。

  robots.txt について（大切）
    検索エンジンは、ドメインの一番上（https://leben-k.github.io/robots.txt）にある
    robots.txt だけを読みます。mitinoeki/robots.txt は置いてありますが、
    それだけでは効きません。
    leben-k.github.io リポジトリに robots.txt がなければ、
    「root-repository/robots.txt」をそのリポジトリの一番上に置いてください。
    すでにある場合は、次の1行を書き足してください。
        Sitemap: https://leben-k.github.io/mitinoeki/sitemap.xml
    ※ robots.txt がなくても、Search Console からサイトマップを送信すれば登録されます。


4. 検索で見つかりやすくするための工夫（作成済み）
--------------------------------------------------
  ・観光地・道の駅ごとに1ページ（観光地27か所・道の駅17駅）
  ・ページタイトルを「〇〇の見どころと近くの道の駅」「〇〇の特産品と近くの観光地」の形に
  ・説明文、構造化データ（観光地・パンくず）、正規URL、OGP（SNS共有用画像）を設定
  ・本文はすべてHTMLに直接記載（検索エンジンが確実に読める形）
  ・ページ同士を相互リンク（観光地 ⇔ 道の駅 ⇔ 次の観光地）
  ・「観光地名 道の駅」「観光地名 近く」「道の駅名 特産品」などの組み合わせ検索を想定

  載せた後に効果があること
    ・Search Console でサイトマップを送信する
    ・運営者サイト（https://leben-k.github.io/）からこのサイトへリンクを張る
    ・SNSなどで紹介する
    ・季節の情報や写真を少しずつ追加し、内容を新しく保つ


5. 掲載内容について
--------------------------------------------------
  ・情報は2026年10月時点で確認できた公開情報をもとに作成しています。
    変わりやすい営業時間・料金・電話番号は掲載せず、各施設の確認を案内しています。
  ・公開前に、特に気になるページの内容を一度ご確認ください。
  ・イラスト、略図、ファビコンはすべてこのサイト用に作成したもので、
    他の画像は使っていません。
  ・略図は位置関係を示す簡略図で、距離は直線距離の目安です。
  ・仁風閣（鳥取城跡）は修理工事のため長期休館中（令和10年度中再開予定）と記載しています。
    再開館したら kanko/tottori-castle.html の該当文を書き換えてください。
